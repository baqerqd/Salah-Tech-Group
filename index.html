القطاع النفطي وحفر الآبار

1. حزمة اليمان لمراقبة منصات الحفر (Rig Monitor System)

منظومة برمجية هندسية متكاملة تتكون من 3 برامج متخصصة تعمل في بيئات منصات حفر آبار النفط، توفر مراقبة حية ولحظية لمعاملات الحفر الحساسة لضمان أعلى مستويات الأمان وسرعة اتخاذ القرار الميداني.

الحزمة تشمل 3 برامج متخصصة ومترابطة:
1. Rig Monitor System (شاشة القيادة الميدانية) 2. Rig Server (خادم ربط وتدفق البيانات الضخمة) 3. Online Watch (المراقبة السحابية الحية عن بُعد)
  • ✓ مراقبة فورية (Real-Time): قراءة ضغط المضخات (SPP)، عزم الدوران (TRQ)، سرعة الدوران (RPM)، وحمل الخطاف.
  • ✓ إنذار مبكر للغازات الخطرة: مؤشرات حية لغاز H2S والغازات القابلة للاشتعال وحالة 10 خزانات طين.
  • ✓ تكامل الذكاء الاصطناعي (AI Co-Pilot): دعم هندسي لاتخاذ القرارات السليمة أثناء الحفر وتفادي الحوادث.
  • ✓ تتبع جغرافي ومراقبة عبر الويب: متابعة مستمرة لمنصات الحفر على الخريطة من غرفة العمليات الرئيسية.
عرض العرض التقديمي الشامل للنظام
المتاجر ونقاط البيع والأقساط

2. نظام الميان المتكامل (Al-Mayan ERP & POS)

حل رقمي شامل لإدارة المتاجر العامة ومحلات البيع بالأقساط والمخازن. مزود بحزمة ضخمة من المعادلات الحسابية الدقيقة، كشوفات السيولة النقدية، وإدارة شاملة للموردين والزبائن.

  • ✓ نقاط بيع ذكية (POS): دعم الفواتير المتعددة، الباركود، الطابعات الحرارية، وشاشات الزبون الإضافية.
  • ✓ نظام أقساط حسابي متقدم: احتساب الفوائد، جدولة مواعيد السداد الشهرية، وتنبيهات فورية للأقساط المتأخرة.
  • ✓ خدمة البيع المباشر عبر الهاتف (Direct Sale): ربط سلة الزبون النشط مباشرة عبر رابط محلي وتأكيد الفاتورة.
  • ✓ لوحة تحكم إدارية وافية: إحصائيات السيولة النقدية المتوفرة، المبيعات اليومية، والمصاريف الخارجية وإنهاء الجلسات.

3. برنامج إيرادات (نظام جباية الإيرادات الحكومية)

نظام مالي وأمني مؤتمت مخصص لدوائر الدولة والوزارات (مثل وزارة الداخلية - دائرة الجنسية والإقامة والدوائر الخدمية) لأتمتة عمليات قبض الرسوم وجباية الإيرادات بسلاسة ودون أخطاء بشرية.

  • ✓ عمليات قبض فورية وآمنة: إصدار الوصولات وتأكيد المقبوضات بلمسة واحدة لإنهاء الطوابير.
  • ✓ دعم الدفع الإلكتروني (POS): تكامل كامل مع بوابات الدفع الإلكتروني المصرفية ونقاط البيع والنقد.
  • ✓ حماية وتشفير عالي: منظومة صلاحيات دقيقة للموظفين ومدراء النظام لمنع أي تلاعب مالي.
  • ✓ كشوفات وجداول زمنية تفصيلية: جرد فوري للإيرادات حسب المناوبات، الأيام، وتصنيفات المعاملات (إصدار هوية، بطاقة موحدة، بدلات فاقد وتالف).

4. برنامج الرزان (Al-Razan PLC & Calibration Suite)

بيئة برمجية رائدة لقراءة سجلات أجهزة الـ PLC الصناعية وإجراء المعايرة الدقيقة. يتيح لأي مبرمج أو مطور بناء واجهات خاصة به والاتصال بالبرنامج عبر الشبكة المحلية للاستفادة الكاملة من القراءات الميدانية.

  • ✓ قراءة متزامنة لـ 50+ قناة: دعم سجلات الـ Holding Address (50 قناة)، Coil Address (50 قناة)، و Numeric Entry.
  • ✓ معايرة فائقة الدقة: معادلات رياضية وهندسية متطورة لتصحيح ومعايرة إشارات الحساسات المختلفة.
  • ✓ تكامل مفتوح للمطورين (API Docs): توثيق شامل وطرق اتصال مشروحة عبر LAN API Port 8080 و Modbus/TCP.
  • ✓ مسح واكتشاف الأجهزة (Discovery Scan): فحص تلقائي وسريع للشبكة لاكتشاف وحدات الـ PLC المتصلة.

5. برنامج اختبار الضغط (Pressure Test Report)

برنامج هندسي متخصص في فحص واختبار ضغوط المضخات ومعدات الآبار (BOP Double Ram, Casing, Valves)، يقدم قراءة حية ومباشرة مع رسم بياني لحظي وتوليد تقارير رسمية جاهزة للطباعة وحفظ PDF.

  • ✓ رسم بياني حي (Live Chart): متابعة مسار الضغط بالـ PSI ثانية بثانية لكشف أي هبوط أو تسريب هيدروليكي فوراً.
  • ✓ تقارير هندسية معتمدة: توليد تقرير فحص كامل بضغطة زر يتضمن بيانات المعدة، المشغل، والضغوط المقاسة.
  • ✓ حفظ مباشر بصيغة PDF والطباعة: أرشفة رقمية سريعة وطباعة فورية لمهندسي الفحص الميداني.
  • ✓ دقة هيدروستاتيكية عالية: دعم اختبارات الضغط العالي (5000 PSI, 10000 PSI) وتوثيق مدة الاستقرار.
